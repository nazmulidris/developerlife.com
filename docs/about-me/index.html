Despite the massive rise of autonomous coding agents and remote cloud VM administration, terminal UI and foundational primitives have largely stagnated since the 1990s.

I am reimagining the terminal for this era, to address the needs of LLM harnesses and ergonomic remote cloud VM admin.

The first thing I am doing is creating better primitives (r3bl-open-core aka ROC) from the ground up in Rust (2.7M+ downloads on crates.io) to bridge the gap in terminal capabilities since the 90’s.

Available today, ROC provides a strictly type-safe, correctness-focused async TUI engine, headless virtual terminal emulation (VTE), low-latency PTY/TTY runtime, CLI/TUI apps (edi, giti), MCP servers, and IDE/browser extensions.

Built on top of this open-source foundation, I’m building an upcoming closed-source suite of terminal apps at r3bl.com (which all work seamlessly over SSH). This includes a local-first collaborative “Google Docs meets Jupyter notebooks” for Markdown and virtual terminal multiplexers.

My focus is on preserving data sovereignty, privacy, and enabling local-first computing, while enhancing developer productivity, knowledge capture & sharing, and workflow management.

Architecture, Platform & Ecosystem #

  • r3bl_tui (Async TUI Engine & VTE Primitives) Open Source: Strictly type-safe async TUI engine with custom CSS/Flexbox layout & rendering engines, Elm-style state, React/JSX-style declarative macros, headless virtual terminal emulation (VTE), low-latency PTY/TTY runtime, and full-featured Markdown editor component.
  • r3bl-cmdr (Interactive CLI & TUI Apps) Open Source: Modal terminal Markdown editor (edi) and interactive Git branch & staging workflows (giti).
  • r3bl-rust-analyzer-mcp-server (AI & MCP Servers) Open Source: High-performance Model Context Protocol (MCP) servers bridging AI coding agents directly with local language servers and toolchains.
  • IDE & Browser Extensions Open Source: Suite of VS Code and Open VSX extensions for Rust development, alongside the R3BL Shortlink browser extension (Chrome and Firefox).
  • Upcoming Local-First Product Suite (r3bl.com) Closed Source: Terminal apps over SSH — collaborative Markdown editing and virtual terminal multiplexers.
